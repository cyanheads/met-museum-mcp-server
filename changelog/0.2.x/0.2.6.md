# 0.2.6 — 2026-08-22

## Added

- **MCP 2026-07-28:** The server supports the current protocol revision alongside 2025-era clients.
- **Community health:** Contributor guidance and a code of conduct join the existing security policy, whose disclosure address now uses the dedicated security alias.

## Changed

- **Tool schemas:** Advertised schemas use Draft 2020-12, reject undeclared root input keys instead of stripping them, and include the structured error envelope so clients can validate declared failures.
- **HTTP sessions:** `.env.example`, the Docker image, and the README now agree on explicit stateless HTTP serving; `auto` remains documented as the framework schema default that resolves to stateful operation.
- **Met API transport:** Framework-managed fetches now cover response-body timeouts, treat object `404` responses as expected misses, and preserve the framework's current retry classification. Search timeouts remain non-retryable `search_timeout` errors.
- **Search result description:** `met_search_collections` now describes `objectIDs` as the current result page rather than the first page.
- **Build and maintenance tooling:** The Bun 1.4 and TypeScript 7 build, test, packaging, agent-skill, and Docker surfaces are synchronized with the current framework scaffold.
