# 0.5.1 — 2026-09-09

## Fixed

- **`met_search_collections` filtered results are intersected against an unfiltered control run of the same query.** Every filter parameter on the upstream `/search` index answered with the union of the genuine keyword matches and a fixed, query-independent floor of unrelated objects; a second run carrying `q` alone now runs in parallel and only IDs present in both survive. `total` is the intersection size, and `no_results` is reachable behind a filter for the first time (#21).

## Added

- **`enrichment.notice`** on `met_search_collections` reports when the control run above could not complete — a keyword broad enough to time out on its own returns the filtered page unchecked instead of failing the call.
